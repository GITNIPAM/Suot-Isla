3. Use Case Diagram Across the Order Lifecycle (15 Points)

Covers all 5 Actors (Customer, Admin, Delivery Personnel / Courier, Payment Gateway, Email Service) across all 7 Stages with explicit <<include>> and <<extend>> relationships.

Lifecycle Stage Primary Actors Core Use Cases Include / Extend Relationships
1. Browsing Customer Browse catalog (16 products), search products, filter & sort (Category, Island Series, Size, Color, Price), view product details Filter & Sort dynamically queries PRODUCTS & PRODUCT_VARIANTS
2. Account Customer Register account, log in (verify against hashed password), manage profile & addresses, view order history Log In <<include>> Verify Hashed Password
3. Buying Customer, Payment Gateway, Email Service Add to cart, update cart, apply coupon, checkout, make payment Checkout <<include>> Validate Stock, Validate Address, Make Payment; Apply Coupon <<extend>> Checkout
4. Order Processing Admin / Staff, Email Service Receive new order, confirm order, update inventory, pack order, update status Confirm Order <<include>> Update Inventory & Send Confirmation Email
5. Delivery Admin, Delivery Personnel / Courier, Customer, Email Service Assign courier, ship order, track order, confirm delivery Ship Order <<include>> Send Shipping Update Email
6. Returns & Refunds Customer, Admin, Payment Gateway, Email Service Request cancellation, request return, approve or reject return, restock item, process refund Request Return / Cancel <<extend>> View Order History; Restock Item & Process Refund <<extend>> Approve Return
7. Admin Management Admin Manage products & categories (CRUD + image upload), manage stock & low-stock alerts, manage customers & RBAC roles Restricted via Role-Based Access Control (admin, staff, courier)

4. FourSys Cloud (Starter Cloud Tier) Deployment & Backend Integration Guide

Designed for direct upload to your FourSys Cloud Starter Cloud Tier (public_html + MySQL Database via phpMyAdmin):

Step 1: Import MySQL Database

In FourSys Cloud Control Panel → MySQL Databases, create a database (e.g. suotisla_db), open phpMyAdmin, and import docs/schema.sql.

Step 2: Connect Forms & Endpoints

All forms already carry semantic action="api/..." and name="..." attributes: checkout.html, auth.html, account.html, and admin.html (with enctype="multipart/form-data" for image uploads).

Step 3: Upload to public_html & Enable SSL

Upload all HTML, assets/, and PHP backend scripts into public_html/ via File Manager or SFTP, and activate the included Let's Encrypt SSL certificate.
